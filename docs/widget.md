# 桌面资源看板

用户目标：无需打开终端，随时看见Mac内存压力和磁盘余量，预览并调用现有工具安全回收，保留正在进行的开发工作。

| 验收项 | 行为 |
|---|---|
| W-01 | 启动默认隐藏面板，只显示菜单栏小图标；主动唤出后显示内存压力、物理/压缩/swap、磁盘可用/总容量；未知字段用破折号或错误提示，不伪造零 |
| W-02 | 15秒自动采样，手动刷新更新时间；窗口可置顶并记住偏好，关窗可从菜单栏或全局快捷键恢复 |
| W-03 | 自动刷新只读采样和小型治理元数据；用户手动操作才扫描或清理，不运行构建、不联网；目标不作为构建门禁 |

主路径：打开App（面板隐藏）→ 左键菜单栏图标或按快捷键 → 查看资源指标 → 切换置顶 → 点击刷新 → 关闭小窗 → 菜单栏图标或快捷键再次唤出。右键菜单栏图标可刷新、查看快捷键和退出。

采样：sysctl 内存压力/swap、host_statistics64 压缩内存、文件系统可用空间。仅读取 `~/.config/dev-resource-guard/config.json`、`~/.local/state/dev-storage/` 下的槽清单及上次plan、`~/.local/state/dev-memory/` 下的观测/暂停标记。可用空间不含预计可清理量；不把压缩量与swap相加当RAM用量。

守护状态仅表达最近观测或暂停标记，不保证调度已启用；未安装守护不影响看板显示。自定义环境变量指定的状态根不自动继承到Finder启动的App，优先使用标准配置文件的state_root；内存状态采用默认目录。

构建方式见README。窗口和置顶偏好保存在本App的UserDefaults；退出App停止采样；执行过程中退出菜单只唤回面板，等待后端结束再退出。关闭窗口仍可从菜单栏或全局快捷键恢复。看板不添加开机启动，不依赖登录账户、网络服务或ELYS配置。

自动验证：可读采样、单位换算、缺值与三种压力标签。实际桌面验证记录在交付说明；人的验收结论不由自动化代填。


## 分类扫描与清理（1.1）

行为规格与验收口径统一维护在[资源看板规格](epics/resource-dashboard/specs/dashboard-actions.md)，[测试入口与边界](epics/resource-dashboard/specs/dashboard-actions.test-cases.md)。

适配器和 runtime 随 App 打包，优先使用已安装的 dev-storage 和 dev-memory，不覆盖现有部署；缺命令时使用内置实现。运行元数据位于 `~/.local/state/dev-resource-guard/dashboard/`；结果未知时保留running/unknown状态，不重复发送清理请求，核实后端日志和进程再处理。退出菜单在操作运行时只唤回面板，关闭小窗不会取消后端。

隔离原生界面测试使用 `ResourceDashboard --test-home <目录>`，目录必须含 `.resource-dashboard-fixture` 标记。缺参或缺标记拒绝回退真实工具。隔离标题不构成真实清理证据。

## 默认后台驻留（1.1.1）

[启动与唤起规格](epics/resource-dashboard/specs/menubar-presence.md)规定首次启动和重启均不自动打开或恢复面板；关闭窗口只隐藏，左键小图标或快捷键按需呼出。菜单栏不常驻容量文字，资源指标保留在提示与面板中。

## 新用户清理（1.2）

行为规格统一维护在[新用户清理规格](epics/resource-dashboard/specs/new-user-cleanup.md)和对应 test-cases。已有缓存入口独立于构建脚本接入；接入设置提供能力检查及明确确认后的自动维护配置。新版单次回收独立于自动暂停，旧后端不兼容时明确提示，保持原状态。

## 1.3 安装后自动维护

使用 scripts/install.py 完整安装。接入设置同时提供「完成安装并开启维护」和「接入项目构建缓存」，显示实际旧/新调度、真实清理回执、项目构建次数和复用证据。旧命令保留，安装后看板使用内置完整协议。自动磁盘范围增加默认 DerivedData 的过期中间目录；模拟器、任务目录仍保留。详细行为见 [自动维护规格](epics/resource-dashboard/specs/automatic-maintenance.md)。

## 1.4 分档自动清理

面板新增「待确认」（勾选后执行或忽略，执行前逐项复核）和「自动记录」（自动档做了什么、保留了什么）两个页签；「接入设置」可开关自动档和询问档。菜单栏图标在有待确认项时亮红点；后台需要提醒时写通知请求，看板（未运行时会在后台启动）发系统通知，点通知打开「待确认」。界面证据用 `ResourceDashboard --test-home <fixture> --render-tab <页签> <输出.png>` 离屏生成，不弹出窗口。规格见 [分档自动清理](epics/auto-cleanup/brief.md)。

1.3.1：默认 Xcode 缓存目录换成指向外接盘等专用目录的链接时照常清理，链接指向不存在的位置时本轮跳过这一类。两类缓存的结果分开记录，失败或跳过直接显示在「自动清理最近结果」，不再只显示「已加载」。项目接入生成的入口目录自带忽略规则，`git status` 不多出文件。
