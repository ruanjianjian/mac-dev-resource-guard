## 意图

新用户刚装上时，不太知道适合自己的清理计划是什么样（RAW-01）。资源看板现在靠写死的规则，跟不上每台 Mac 自己的变化：10-30 一个任务里有 26 GB 的 Swift 包构建输出，规则不认识，内置盘跌到 15 GB 才被发现，最后靠改代码才修好（RAW-02）。

本 epic 让用户自己的本地 agent 当「资源管理 agent」：
- 装好就出第一版计划并开跑；
- 把用户的每个取舍、自己学到的教训都记成记忆，按记忆改计划和设置；
- 计划连续几次不用改就定稿，之后只在出现新东西时重开（RAW-01 第 5 条）。

资源看板的界面退到第二位，主要用来看 agent 的计划、管 agent 的权限（RAW-01 第 3 条）。

## 非目标

- **后台不无人值守地跑 agent。** 不用 agent 的命令行在后台自己跑，因为每次都花用户的模型额度，还要给后台改配置的权限（决策卡 A01 没选 C）。
- **资源看板里不内置模型。** 不拿用户的密钥直接调模型，判断都交给用户自己的 agent。
- **记忆不放进各个 agent 自己的记忆里**（RAW-03）。也不上传，只在本机。
- **计划定稿后不再每周微调**（RAW-09）。
- **agent 改不动安全底线**（RAW-05）。

## 全局约束

- **安全底线写死在代码里**（RAW-05），计划和 agent 都改不动：
  - 正在用的不动；
  - 有未提交或未推送改动的不删；
  - 会丢东西的删除先问用户；
  - 模拟器不放外接盘；
  - 外接盘拔掉时只报错、不在内置盘另建一份；
  - 判断不了的保留。
- **每次改动都留痕**（RAW-07）：agent 改计划或设置时，写明改了什么、为什么、依据哪几条记忆，并通知用户一次。
- **锁住的不碰**（RAW-07）：用户锁住的设置和规则，agent 只能建议，不能改。
- **记忆只记决定和教训**（RAW-04）：后台自动做的动作照旧只进日志，不进记忆。
- **哪个 agent 都能用**（RAW-03、RAW-06）：
  - Claude、Codex 读写同一份记忆和计划；
  - 没有定时任务能力的 agent，每周复查退回成一条通知。
- **沿用「装好就省心」的约束**：
  - 装完不弹面板；
  - 只问一次；
  - 改过的开发设置都能一键还原；
  - 外接盘拔掉只报错、不在内置盘另建缓存。
