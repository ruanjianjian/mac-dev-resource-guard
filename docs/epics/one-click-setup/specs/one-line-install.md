# Spec: 一条命令安装 v1

## 原始输入

原话全量在 epic 的 [raw-input.md](../raw-input.md)；本 feature 依据 RAW-01、RAW-02、RAW-12、RAW-36。讨论过程：决策卡 https://claude.ai/artifact/B2QaPqf6Fc41G2LptKy1ez。

## 意图

现在装资源看板要先克隆仓库、再跑安装脚本，看不懂终端的同学会卡住（RAW-01「不够傻瓜」）。改成复制一行命令粘贴到终端：它自己下载源码、在本机编译、装好 App 和后台任务。装完不弹面板，App 第一次启动后在后台做一次体检，发一条「体检完成」通知，点开就是体检页（RAW-02）。以后升级也是同一行命令。

第一次安装时只问一次：要不要默认打开共享构建缓存、自动清理和外接盘（插着外接盘才问这一项）。同意了，装完这几项就已经开好，不用再去面板里点（RAW-36）。让 agent 装时，由 agent 在对话里问，用一个环境变量把回答带给安装脚本。

## 非目标

- 不做需要苹果付费开发者账号的签名、公证安装包（RAW-12）。
- 不替用户安装 Xcode 或命令行工具：缺了就停下，请系统弹出安装提示。
- 不经 Homebrew 分发。
