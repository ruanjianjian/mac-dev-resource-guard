# Spec: 体检页与一次确认 v1

## 原始输入

原话全量在 epic 的 [raw-input.md](../raw-input.md)；本 feature 依据 RAW-01～03、RAW-06。讨论过程：决策卡 https://claude.ai/artifact/B2QaPqf6Fc41G2LptKy1ez。

## 意图

用户点开看板，第一个页签就是「体检」：上面是内置盘还剩多少、空间去哪了；下面是三项建议——共享构建缓存、自动清理、使用外接盘——每项一个开关，另有「全部按推荐开启」（RAW-02）。任务目录和外接盘由工具自己找到并列出来，用户看一眼确认，不用再手写配置文件（RAW-03）。

## 非目标

- 不在体检页里直接删东西：会丢东西的清理仍走「待确认」。
- 不扫描整块磁盘：只看开发常见的位置和找到的任务目录。
- 不替用户决定外接盘：没插外接盘时，「使用外接盘」一项不可开。

## 验收标准

| ID | 级 | Given | When | Then | 落点 | 状态 | 证据 |
|---|---|---|---|---|---|---|---|
| AC-01 | [核] | 打开面板 | 看第一个页签「体检」 | 显示内置盘剩余空间，以及空间去哪了：任务目录、模拟器、Xcode 缓存、各工具缓存、废纸篓、下载里的安装包、Docker 等。每类写大小、在内置盘还是外接盘、工具会怎么处理（自动 / 先问你 / 只提醒）；读不到大小的写原因，不写 0 | mac原生、CLI后端 | ⬜ |  |
| AC-02 | [核] | 本机有 git 仓库，以及它们的工作区（含 Claude、Codex 建的） | 体检 | 自动找出「放任务的文件夹」，显示每个文件夹里有几个任务；嵌套的只算最外层，主目录本身不算；不翻桌面、文稿、下载这几个受系统保护的文件夹，体检不会因此弹出访问询问 | CLI后端 | ⬜ |  |
| AC-03 | [核] | 插着外接盘 | 体检 | 推荐一块 APFS 格式、可写、不是时间机器备份盘的外接盘，显示剩余空间；有多块时推荐剩余空间最大的；网络盘、只读盘、时间机器盘不推荐 | CLI后端 | ⬜ |  |
| AC-04 | [核] | 体检页列出三项建议 | 点「全部按推荐开启」或单项开关 | 对应设置写进设置文件（任务目录、外接盘、自动档、询问档、缓存共享、Xcode 编译缓存），体检页随即显示已开启；不再弹第二次确认 | mac原生、CLI后端 | ⬜ |  |
| AC-05 | [边] | 用户以前手写过任务目录和外接盘 | 体检并开启 | 手写的保留，新找到的追加，同一个目录不重复 | CLI后端 | ⬜ |  |
| AC-06 | [边] | 选了外接盘 | 开启 | 当场试写一次外接盘，macOS 弹出访问询问；用户拒绝时，体检页写「需要授权」，其他两项照常开启 | mac原生、CLI后端 | ⬜ |  |
