# Spec: 菜单栏封面 v1

## 原始输入

原话全量在 epic 的 [raw-input.md](../raw-input.md)；本 feature 依据 RAW-15～20、RAW-35、RAW-36、RAW-39、RAW-40。讨论过程：本会话里三轮视觉稿（书封面多色 → 单色两版 → 三个更优雅的方向，用户选「一张封面」，详情页用「留白排版」）。

## 意图

用户觉得看板「乱七八糟」，要以用户体验为中心、小清新（RAW-15），颜色要更少（RAW-16）、更优雅（RAW-17）。打开看板时，用户只关心三件事：还剩多少、有没有在帮我管、有没有要我拍板的。

所以点菜单栏图标，弹出的是一张像书封面的小面板：一块纯色、一个圆环、几行字。点圆环、左下角、右下角，分别进入「空间去哪了」「帮你管着」「等你确认」三张素净的页面。原来那个 7 个页签的大窗口去掉了，所有功能都在封面里（RAW-36）。

接了几块显示器时，面板在你正在看的那块屏幕上弹出（鼠标在哪块就是哪块），不会跑到另一块屏幕去（RAW-35）。

## 非目标

- 不再保留原来的大窗口：实时概览、磁盘缓存、开发后台、待确认列表、自动记录、接入设置的作用已由封面各页、后台和命令行接手（内存回收照常在后台跑，不在界面上露出）。
- 不跟随系统深色模式换色：封面和页面用固定的配色。
