# Mac开发资源看板

让开发者在同一个本机窗口查看资源、预览可回收内容并调用现有保护策略完成回收。

| 功能 | 规格 |
|---|---|
| 分类扫描、安全操作与全局唤起 | [dashboard-actions](specs/dashboard-actions.md) |
| 默认隐藏与按需唤起 | [menubar-presence](specs/menubar-presence.md) |

约束：复用已安装dev-storage/dev-memory及其锁、状态、保护范围；不覆盖后端、不新增调度、不打断正在进行的开发工作。
非目标：扩大删除白名单、删除设备数据、解除他人保护、用磁盘目标阻挡编译。其中「扩大删除白名单、删除设备数据」两条已由 [分档自动清理](../auto-cleanup/brief.md) 在三档规则内有条件放开（2026-10-27）：设备数据只走询问档，由用户确认后才删。
