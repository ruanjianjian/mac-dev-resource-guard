## 原始输入

[逐字原始输入](dashboard-actions.raw-input.md)，RAW-01～09；实现需求为RAW-06，全局快捷键为RAW-07，提交合并及旧App收尾为RAW-08～09。

## 意图

开发者希望直接在资源看板查看哪些缓存或开发后台可以回收，并在操作前知道哪些内容会保留。看板提供分类预览与确认入口，实际回收继续由现有工具执行。

## 非目标

不扩大缓存删除白名单，不删除模拟器或真机数据，不解除pin/lease，不安装新调度，不把空间阈值当构建门禁。没有账号切换、远端数据写入或服务端泳道；本功能仅操作本机已安装命令。

## 流程

打开概览 → 选择磁盘缓存或开发后台 → 手动扫描/诊断 → 查看分类及保护原因 → 对符合条件的结果发起确认 → 现有后端重新核对后执行 → 显示回执；错误、busy、过期或未知状态不会直接执行清理。

预览有效期为五分钟，仅可使用一次。磁盘执行时按相同规则重新扫描，实际项目可能与预览不同。内存accepted/pending不等同已退出；守护暂停时不会被此入口恢复。

## 安装与验证边界

macOS 13+，Python 3.9+，本地按架构编译。看板概览独立可用；操作需要已安装后端。没有对外网络API、GrowthBook或dev/fat配置。真实本机仅验证扫描、诊断、保护结果和快捷键；实际清理请求通过显式假CLI验证，未宣称真实释放量。人类未确认测试结果。

## 实现前AI总结
