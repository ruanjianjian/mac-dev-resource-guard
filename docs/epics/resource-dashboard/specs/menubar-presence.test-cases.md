# 按需唤起测试用例

| 用例 | AC | 操作 | 预期 |
|---|---|---|---|
| menu-bar-presence | AC-06 | 退出并启动App，观察桌面和菜单栏；右键图标查看菜单；主动显示后关闭并重启 | 不自动显示窗口，只保留小图标；右键能找到刷新、实际快捷键、退出；历史窗口偏好不会使启动弹窗 |
| panel-reveal | AC-07 | 隐藏时左键小图标，关闭，再从其他App按⌃⌥⌘S，关闭再左键 | 两种入口均直接显示面板，关闭后进程和菜单栏继续存在，不触发扫描/清理 |

红证据：1.1.0安装版退出重启后立即显示面板，不符合AC-06；修改前截图保留在本机任务证据。绿证据由用户明确授权后，原生AX及系统HID事件直接在最终安装版记录，并配合真实窗口/图标截图；早期受reopen干扰的CUA按键观察不计作严格全局热键证据。

采样和后端测试复用既有 `ResourceDashboard --self-test`、`python3 -m unittest discover -s tests -p test_dashboard.py -v`。本轮未改变清理工具或协议，不重复执行未受影响的真实资源操作。

原生组件证据使用真实AppDelegate和NSStatusBarButton；详见规格的证据边界。系统菜单栏位置命中没有直接覆盖，不将组件夹具截图表述为该环境的直接鼠标手测。

最终实际安装版记录：冷启动/再次open均0窗口；系统全局键两轮0→1；系统图标AXPress两轮0→1，关闭均回到0。右键菜单和退出采用同源真实NSStatusBarButton组件computer-use验证。没有把失败的像素坐标注入计作通过。
