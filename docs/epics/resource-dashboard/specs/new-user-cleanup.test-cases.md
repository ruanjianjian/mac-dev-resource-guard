# 新用户清理测试用例

- TC-NU-01 / AC-NU-01：空 HOME 无命令和 devlease；放置过期 Xcode 中间缓存、Products、被 pin 缓存；App 扫描→取消→确认→复扫。只确认对象删除，Products/pin 保留；近期修改、打开文件、编译进程出现时拒绝；过期预览不执行。
- TC-NU-02 / AC-NU-02：暂停标记保留；可回收受管后台单次退出，不在预览的新对象保持，活跃/未知/冷却/pending 不回收；旧后端有升级提示。
- TC-NU-03 / AC-NU-03：App 接入检查→安装确认取消→确认安装→自动维护默认未启用；隔离 LaunchAgent 安装、加载、执行一轮、关闭并移除，未触及真实任务；已有命令冲突保留。
- TC-NU-04 / AC-NU-04：大项大小与保留原因可见；选择任务目录并复制核对命令；关窗后快捷键、菜单栏唤起；自动启动不占桌面。
