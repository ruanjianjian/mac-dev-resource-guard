# 安装后持续维护与构建缓存复用

产品文档：https://hcnqwxuq730f.feishu.cn/page/OrtGm3ZDDdm1cEaDAnVctlBBn7g

用户预期：装好可自动清理，也有构建缓存共享能力；继续推进至提交、合并、安装。此前真实扫描发现旧接口禁用按钮、旧调度漏报和大目录统计超时。

## 行为

- 推荐安装命令构建并安装 App，安装独立完整运行时、原子更新自有启动入口、开启自动维护。启动面板仍隐藏。仅构建 App 时可从接入设置完成同一安装动作。
- 每 12 小时及安装后自动清理固定槽与默认 DerivedData 四类中间目录；默认 DerivedData 至少七天。复核 pin、lease、槽锁、最近使用、文件身份和占用。既有源码、Products、任务、设备、登录态保留；磁盘水位不阻止构建。
- 复用可验证的旧内存 tick，识别真实加载状态；旧公开调度仅在禁止新派发并确认空闲后迁移，运行中保留并可重试。无法确认能力的其他调度显示部分完成，不宣称已开启、不重复启动。
- 保留原 dev-storage/dev-memory；完整安装后的看板使用内置协议，并从合法唯一的旧槽清单复用缓存根、状态及阈值。旧 tail 能力协商；暂停且不支持单次的旧后台保留，绝不发送未知停止命令。
- 项目选择后只生成 `.dev-resource-guard/xcode-build`，不改原脚本；调用该入口以工作树、工具链、平台、配置复用槽。不同工作树可变产物隔离；Go/npm 等沿用工具全局缓存。真实 build 成功两次才显示同槽复用已验证，查询命令不计数。
- 自动维护可暂停；不杀在途工作，执行到下一候选时复核暂停。显示最近真实回执，目录计量与全盘净变化分开。大项统计等待上限 120 秒，失败显示未知。

## 实现期验证调整

CH-01：用户 2026-10-27 明确说「你别老是弹出这个面板，挡住我工作了」。原生面板已隐藏，不再通过 UI 操作。此前原生实际看到已加载的旧内存守护、新磁盘调度和真实 5 项回执；最终 UI 文案与项目选择完整复验未完成。上述三条核心行为继续通过真实后台/CLI验收，原生最终复验单列为 AC-AUTO-04，随 PR 保留该豁免，不阻止用户要求的提交交付。

红证据：旧源码没有 service.py 自动维护入口；旧版暂停/单次协议与复用证据回归不具备。新测试包含旧格式调度忙碌禁止 bootout、扫描中暂停保留、旧 tail 暂停零停止请求与未暂停旧操作。

不承诺可清固定容量。设备与 MCP 缺少协议时保留；Go、会话、任务大项仅统计。安装保留原私有命令；未知自定义调度仍需原工具管理。人工未验收不作已验收声明。
