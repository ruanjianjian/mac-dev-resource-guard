# Spec: 自动档清理 v2（基于资源看板 1.3）

## 原始输入

原话全量在 [tiered-auto-cleanup.raw-input.md](./tiered-auto-cleanup.raw-input.md)；首轮 RAW-01～19：需求主体是 RAW-14～16，拍板的选择题回答是 RAW-17～19。本轮新增 RAW-20～21：改到 1.3 基线上。

## 意图

同时开很多任务的开发者，任务目录里的构建产物和放着不用的任务目录越积越多，内置盘几天就被占满（RAW-14、RAW-15）。资源看板 1.3 每 12 小时清一次过期的 Xcode 缓存，但任务目录和模拟器只统计、不处理，也不看剩余空间（RAW-20）。

这个功能接在 1.3 的定时任务上，默认每 30 分钟看一次可用空间（间隔可配置；1.3 的过期缓存清理仍按原来的 12 小时）。低于提醒线时，自动做以下几件不会丢任何东西的事：
- 把闲置的任务目录整个挪到用户配置的外接开发盘；
- 删掉闲置任务里能重新生成的构建产物；
- 清掉系统已判为不可用的模拟器和开发工具自带的缓存。

腾到目标线以上就停。

**用语**：
- **任务目录**：用户在配置里登记的「任务根目录」下的每个子目录，一般一个任务一个，里面是这个任务用到的若干份代码。
- **闲置**：同时满足三条：
  - 没有程序正在里面运行或打开文件；
  - 最近 N 天里面没有文件被改写（N 由用户配置，默认 3 天）；
  - 没有被标记为保护（pin）。
- **外接开发盘**：用户在配置里指定的另一块盘上的目录。
- **自动档开关**：本功能自己的开关，和 1.3 安装时开启的过期缓存清理分开。

## 非目标

- 不删除整个任务目录、不删除正常的模拟器、不关闭开着的模拟器：这些归 [ask-first-confirm](ask-first-confirm.md)。
- 不清理、不搬迁正在使用的任务目录。
- 账号切换 / 可见性：不适用。这是单机单用户工具，没有账号概念。
- 客户端展示名称和图标：不适用。不新增给 agent 用的工具。

## 验收标准

| ID | 级 | Given | When | Then | 落点 | 状态 | 证据 |
|---|---|---|---|---|---|---|---|
| AC-01 | [核] | 自动清理已打开，内置盘可用空间低于提醒线，配置了外接开发盘且已连接、空间足够，有任务目录闲置满设定天数 | 到了检查时间 | 按闲置时间从久到短，把这些任务目录整个挪到外接开发盘，原位置留一个指向新位置的链接，代码、git 记录、构建和 1.3 生成的项目入口照常能用；可用空间回到目标线以上就停 | CLI后端 | | |
| AC-02 | [核] | 同 AC-01，但没配置外接开发盘或外接盘没连接 | 到了检查时间 | 不搬迁，改为删除这些闲置任务目录里能重新生成的构建产物（编译缓存、依赖安装目录、Flutter 工具缓存等，固定名单），源码、配置文件和不在名单里的文件一个不动；已经挪到外接盘的任务目录，原位置的链接保留不动；看板提示「外接开发盘未连接」 | CLI后端、mac原生 | | |
| AC-03 | [核] | 某任务目录有程序在里面运行，或设定天数内有文件改写，或被标记为保护 | 到了检查时间 | 这个目录完全不动，构建产物也不删；记录里写明保留原因。有未提交改动但已闲置的目录可以搬迁、可以删构建产物，因为这两样都不会丢源码 | CLI后端 | | |
| AC-04 | [核] | 搬迁过程中目录里的文件发生变化，或复制前后文件数不一致 | 搬迁该目录 | 放弃这一次，删掉外接盘上的半成品，原目录原样保留，下一轮再试 | CLI后端 | | |
| AC-05 | [核] | 可用空间低于提醒线，系统里有被标为「不可用」的模拟器（例如它依赖的 iOS 版本已删除），开发工具的缓存在这块盘上 | 到了检查时间 | 删掉不可用的模拟器，用开发工具自带的清理命令清它们的缓存；正常的模拟器一台不动 | CLI后端 | | |
| AC-06 | [核] | 可用空间高于提醒线，或自动档开关没打开（安装和从 1.3 升级后的默认状态） | 到了检查时间 | 自动档什么都不删、不搬，1.3 原有的过期缓存清理照常；看板显示「自动档未打开」及打开方法，或显示「空间充足」 | CLI后端、mac原生 | | |
| AC-07 | [核] | 上一轮还没跑完，1.3 的过期缓存清理正在跑，或用户正在看板里手动清理 | 新一轮检查触发 | 新一轮直接跳过，同一目录不会被两轮同时处理 | CLI后端 | | |
| AC-08 | [核] | 自动档处理过若干项 | 打开看板 | 在 1.3 的「自动清理最近结果」旁看到「自动处理记录」：每次处理了哪些目录或缓存、做的是搬迁还是删除、腾出多少空间，以及保留下来的项和原因 | mac原生 | | |
| AC-09 | [边] | 搬迁到一半时断电、拔盘或进程被杀 | 下一次检查 | 先收拾半成品：原目录还在，就删掉外接盘上不完整的副本；原目录已换成链接、外接盘上副本完整，就算完成。不会出现原目录和链接都不在的情况 | CLI后端 | | |
| AC-10 | [边] | 用户改了闲置天数、任务根目录、外接盘路径或检查间隔 | 下一轮检查 | 按新值执行；配置写错（路径不存在、天数不是正数）时自动档这一轮不清理，看板提示哪一项错了。这些设置单独存放，1.3 和更早版本的命令照常读取原有配置，不因新设置报错 | CLI后端、mac原生 | | |
