# Spec: 询问档确认 v1

## 原始输入

原话全量在 [ask-first-confirm.raw-input.md](./ask-first-confirm.raw-input.md)；首轮 RAW-01～09：需求主体是 RAW-06，拍板的选择题回答是 RAW-07～09。本轮新增 RAW-10～11：改到 1.3 基线上。

## 意图

有些清理会丢东西：
- 删模拟器，会丢掉上面登录的测试账号；
- 删任务目录，以后要用得重新拉代码；
- 关掉开着的模拟器，会打断正在看的画面。

开发者希望这些「相对危险」的清理先问一声，自己确认了才做（RAW-06）。之前每次都要开发者自己发现空间不够、再一台台指名删除（RAW-02、RAW-04）。

资源看板 1.3 对模拟器和任务目录只统计大小，看板写着「不会关闭或删除模拟器」（RAW-10）。本功能上线后，这句改为「需要你确认后才会关闭或删除」。

这个功能在发现这类候选时发一条系统通知。用户在看板的「待确认」里看到每一项的大小、建议理由和做了会失去什么，勾选后确认；执行前工具再逐项核对一次。

## 询问档包含的四类

| 对象 | 条件（天数、小时数用户可配置） | 做什么 | 会失去什么 |
|---|---|---|---|
| 已关机的模拟器 | 最近 N 天没开过（默认 7 天） | 删除 | 上面装的 App 和登录状态 |
| 开着的模拟器 | 最近 N 小时没有任何开发工具连着它（默认 4 小时） | 关机 | 当前画面和 App 运行状态 |
| 任务目录 | 闲置满 N 天（默认 7 天），且所有代码改动都已提交并推送 | 删除，包括已挪到外接盘的 | 本地的构建产物和未入库的文件，要用时得重新拉代码 |
| iOS 运行时 | 没有任何模拟器（包括关机的）在用 | 删除 | 以后要建这个版本的模拟器得重新下载 |

## 非目标

- 有未提交或未推送改动的任务目录、开着且有开发工具连着的模拟器、被标记为保护的对象，不进入待确认列表，这是永不档。
- 不自动执行任何一项询问档动作，也不设「超时默认同意」。
- 不通过飞书或邮件询问，只用系统通知加看板。
- 账号切换 / 可见性：不适用。单机单用户。
- 客户端展示名称和图标：不适用。

## 验收标准

| ID | 级 | Given | When | Then | 落点 | 状态 | 证据 |
|---|---|---|---|---|---|---|---|
| AC-01 | [核] | 出现上表任一类候选 | 后台检查完成 | 看板「待确认」列出每一项：对象名称、占用大小、为什么建议、做了会失去什么；菜单栏图标出现红点；发出一条系统通知，点通知打开看板并停在「待确认」 | CLI后端、mac原生 | | |
| AC-02 | [核] | 待确认列表里有多项 | 用户勾选其中几项并确认 | 只执行勾选的项；每一项执行前重新核对条件（仍关机、仍闲置、仍无未推送改动、仍没人用），核对不过的跳过并写明原因；结果逐项显示「已完成 / 已跳过 / 失败」，红点随列表清空消失 | CLI后端、mac原生 | | |
| AC-03 | [核] | 待确认列表里有某一项 | 用户点「忽略」 | 该项不执行，也不再为它发通知；它的状态变化后（例如模拟器又被用过，之后再次闲置满天数）才会重新出现 | CLI后端、mac原生 | | |
| AC-04 | [核] | 有候选但空间仍高于低水位 | 连续多轮检查 | 同一天最多发一次通知；可用空间跌破低水位时立即发一次（同一次跌破只发一次），通知写明当前剩余空间 | CLI后端 | | |
| AC-05 | [核] | 任务目录有未提交或未推送的改动，或模拟器开着且有开发工具连着，或对象被标记为保护 | 后台检查 | 这些对象不出现在待确认列表里 | CLI后端 | | |
| AC-06 | [核] | 同一项被重复确认（连点两次、开了两个看板窗口、自动档恰好也在处理同一目录） | 确认执行 | 同一项只执行一次，第二次显示「已处理或正在处理」 | CLI后端、mac原生 | | |
| AC-07 | [边] | 一次确认了多项，其中部分失败（例如删除时被占用） | 执行结束 | 成功的照常完成；失败的留在列表里，显示失败原因，可以再次确认 | CLI后端、mac原生 | | |
| AC-08 | [边] | 看板没有在运行 | 后台检查出新的候选 | 仍会发系统通知；点通知启动看板并打开「待确认」；待确认列表不因看板没开而丢失 | CLI后端、mac原生 | | |
| AC-09 | [边] | 删除任务目录 | 用户确认执行 | 连同它在代码仓库里的工作区登记一起清理干净，主仓库不留失效记录；外接盘没连接时，已挪到外接盘的目录这一项显示「外接盘未连接」，不执行 | CLI后端 | | |
